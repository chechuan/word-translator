# 研途笔记 · 考研资料整理

以“分组 → 专题 → 论述题 → 标准答案”组织个人题库。沿用原翻译项目的 GitHub / Vercel 部署，正式域名为 https://translate.cc1204.cn。

## 使用

- 初始框架包含用户指定的 5 组、11 个专题，题目由用户录入；旧题库中未修改、未使用的默认示例题会自动清理。
- 在完整架构图上同时查看五组知识。点击分组、专题或题目只选中节点，在保持正常大小的文字操作栏中新增题目、编辑内容或开始默写；旁边的 ＋/－ 控制展开与收起。长题目自动换行并增高，完整显示。
- 支持五组完整架构图、逐级展开和收起、按住空白处无边界自由拖动画布、窗口变化时自适应、适应整图、跨分组搜索，以及专题和题目增删改。
- 架构图铺满整个窗口，顶部工具、角落缩放和选中节点操作均浮动显示，不再占用固定行。专注模式隐藏顶部工具栏，按 Esc 或“退出专注”恢复，当前浏览器会记住选择。
- 电脑默认用滚轮或触控板双指滑动移动画布；触控板捏合、Option / Alt + 滚动缩放。底部“滚动：移动／缩放”可切换普通滚动的行为，选择仅记在当前浏览器，适合不同设备分别设置。
- 标准答案原文和记忆关键词均默认收起，点击题目旁的 ＋ 显示两个独立的展开入口。选中题目、编辑保存或展开专题不会自动显示答案；详情弹窗内也分别点击标题展开。
- 手机可单指拖动画布、双指张开放大或合拢缩小，缩放跟随两指中心；抬起一根手指后可继续拖动。轻点节点仍只选中，拖动或缩放不会误触展开按钮。
- 选中分组、专题或题目后，可用“上移／下移”调整同一父节点下的顺序；排序自动保存，题目的答案、关键词和学习进度随节点保留。
- 操作栏可直接删除节点。删除分组或专题会连同子节点删除，确认框说明范围，完成后提供“撤销”。至少保留一个分组；选中总框架可新增分组。答案节点可单独清空标准答案。
- “默写题目框架”先隐藏当前专题的题目，默写后展开对照。
- 记忆关键词支持按（1）（2）（3）分行填写；查看答案和默写时按顺序分条显示，条内的逗号、顿号保留。
- “默写论述答案”隐藏答案，支持显示记忆关键词、手动对照、自评掌握程度，以及上下题切换。
- 题库、掌握进度和默写草稿自动同步到个人 Neon 数据库，同时在当前浏览器保留本地备份。换设备打开同一网址即可读取云端题库；网络中断时可以继续编辑，恢复连接后再同步。
- 首次接入时会将原浏览器题库上传到空的云端题库。遇到两份不同内容或多设备同时修改时，暂停上传并提示选择，选择前可下载另一份备份，不会静默覆盖。
- 右上角可导出 JSON 备份，在另一设备通过右上角“导入”导入。导入前校验格式并提示替换范围，确认后自动下载原题库备份。
- 删除需确认，删除提示提供撤销；原翻译源码仍保存在 Git 历史中。

## 开发与验证

```sh
npm install
npm run dev
npm test
npm run build
```

默认开发地址为 http://localhost:3000。推送 GitHub 的 main 分支后，由现有 Vercel 项目自动发布。发布后须检查部署状态和正式域名内容。

## 个人云端配置

1. 在自己的 Neon 账户创建 PostgreSQL 项目，复制连接字符串。
2. 在自己的 Vercel 项目 Production 环境中添加 Secret 类型的 `DATABASE_URL`，值为完整的 `postgresql://…` 连接字符串。开发时可在不提交的 `.env.local` 中配置。
3. 发布新版本后，服务端自动创建 `yantu_study_documents` 表。连接字符串只在服务端使用，不发送给浏览器，也不要提交到 Git。

没有配置时只保留本机数据并提示云端不可用；代码只接受 `.neon.tech` 的数据库地址，没有其他存储地址或回退服务。每次更新在数据库中保留最近 20 个历史版本。

按当前使用要求，网址无需账号或口令，所有访问者使用同一份题库，可以查看及修改。右上角的导出功能可另存独立备份。
