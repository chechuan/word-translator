# 拾史 · 近代史思维与默写

以“分组 → 专题 → 论述题 → 标准答案”组织个人题库。沿用原翻译项目的 GitHub / Vercel 部署，正式域名为 https://translate.cc1204.cn。

## 使用

- 初始框架包含用户指定的 5 组、11 个专题，以及“辛亥革命的历史意义”示例题，答案待录入。
- 在完整架构图上同时查看五组知识。点击专题旁的 ＋ 新增题目；点击专题展开题目，点击题目展开答案，使用编辑按钮补充内容和提示词。
- 支持五组完整架构图、逐级展开和收起、拖动画布、Option（⌥）/ Alt + 鼠标滚轮缩放、适应整图、跨分组搜索，以及专题和题目增删改。
- “默写题目框架”先隐藏当前专题的题目，默写后展开对照。
- “默写论述答案”隐藏答案，支持提示词、手动对照、自评掌握程度，以及上下题切换。
- 题库、掌握进度和默写草稿保存在当前浏览器的 localStorage 中，不需要账号或 API Key，也不自动跨设备同步。
- 右上角可导出 JSON 备份，在另一设备通过“更多 → 导入题库备份”导入。导入前校验格式并提示替换范围，确认后自动下载原题库备份。
- 删除需确认，删除提示提供撤销；原翻译源码仍保存在 Git 历史中。

## 开发与验证

```sh
npm install
npm run dev
npm test
npm run build
```

默认开发地址为 http://localhost:3000。推送 GitHub 的 main 分支后，由现有 Vercel 项目自动发布。发布后须检查部署状态和正式域名内容。
