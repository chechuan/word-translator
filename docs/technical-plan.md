# 研途笔记技术说明

- Next.js 15 / React 19 / TypeScript，页面为客户端交互，服务端预渲染初始框架。
- `lib/study.ts` 定义题库模型、初始框架、搜索和 Zod 导入校验。
- `app/architecture-map.tsx` 实现五组完整架构图、逐级展开、答案节点、画布拖动和缩放。`app/page.tsx` 负责题目编辑、默写、自评和 JSON 导入导出。
- `lib/canvas-gestures.ts` 跟踪全部触摸指针，以两指距离比缩放并锚定中心位置；触点数量变化时重设起点，单指继续拖动不跳动。点击与拖动使用移动阈值区分，手势结束后拦截误点击；触点取消和窗口失焦时清理状态。
- `app/globals.css` 提供响应式布局，画布使用独立的平移和缩放坐标，拖动不受内容大小或滚动边界限制。ResizeObserver 在自动适应模式下重算整图视野；手动移动后，窗口缩放保留视图中心。普通滚轮围绕指针缩放，按住空白处拖动画布。
- localStorage key 仍为 `shishi-history-v1`，版本号为 1；题库、草稿、自评统一备份，附加 `_cloud` 保存最近同步的版本号和内容指纹。数据与同步标记一次写入，读取失败保留原始内容。导出的 JSON 不含同步标记。
- 所有题目和答案均以 React 文本渲染，不执行用户输入 HTML；JSON 导入限制为 10 MB 并验证全局 ID 唯一性。
- `app/api/study/route.ts` 提供同源 GET / PUT。数据库连接只读取服务端 `DATABASE_URL`，必须是个人 Neon 项目连接字符串；`lib/neon-store.ts` 限制主机后缀为 `.neon.tech`，无其他存储回退。旧翻译 API 已移除。
- 数据统一存放在个人 Neon 的 `yantu_study_documents` 表，`main` 行保存 JSONB 题库、版本号及最近 20 个历史版本。PUT 用期望版本号进行原子更新，过期版本返回 409，保留历史与写入在同一条 SQL 内完成。
- `app/use-cloud-study.ts` 在编辑后延迟 700ms 同步，写入串行执行；页面可见时每 15 秒读取新版本，重新联网或聚焦时也尝试读取。打开编辑对话框时暂停拉取，保护未保存的输入。
- 首次读取比较本机内容、上次同步指纹和云端内容：空云端接收旧浏览器题库，空浏览器使用云端题库，单边修改继续同步。两边均有不同修改时保留本地并暂停上传，用户可先下载另一份备份再选择使用哪一份。网络失败期间继续保存本地备份，恢复后重新检查版本。
- 按使用要求不设置登录和口令，同一网址的访问者使用同一份题库；API 校验格式、写入来源、请求大小及版本，但不提供身份隔离。数据库连接字符串不进入客户端代码。
- 纯函数测试覆盖初次迁移和冲突判断；通过 PGlite 的 PostgreSQL 引擎验证 SQL、并发版本检查、历史数量和存储重读。发布后另行检查真实 Neon 接口及跨浏览器读取。
- 清理浏览器数据不会删除已同步的云端内容；未同步内容仍需保留浏览器或使用 JSON 导出备份。
